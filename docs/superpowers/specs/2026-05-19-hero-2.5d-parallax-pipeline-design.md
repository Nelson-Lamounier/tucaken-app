## Revision 2026-05-19 — Conveyor Redesign (active)

The 2.5D mouse-tilt parallax approach was implemented then rejected: the hero
copy must NOT move on hover, and the effect should resemble voxr.ai — a static
headline over a full-bleed animated processing backdrop.

**New approach: full-bleed "application conveyor" backdrop.**

- Full-bleed absolute backdrop in `HeroSection` (`bg-zinc-950`, behind text,
  legibility scrim). No pointer interaction anywhere.
- Horizontal **belt** scrolls continuously right→left — seamless infinite loop
  via two identical track copies, `transform: translateX` only (S-tier).
- **Application items** ride the belt evenly spaced (repo-proof mini-tiles),
  moving R→L with it.
- **Processing stations**: 3 fixed vertical scanner gates the belt passes
  under; item state flips as it crosses: `inbound → scanning → qualified`
  (opacity/glow only — no layout properties).
- Hero text + 2 CTAs (`→ /sign-in`) + founder note: centered, **static**,
  overlaid on top.
- Reduced motion: belt + items frozen in a populated arranged frame; no
  scroll/scan; text fully readable.

### Code delta vs original

- `PipelineStage.tsx` REMOVED → replaced by `ConveyorBelt.tsx` (pure
  CSS-driven backdrop; no pointer/spring/3D/MotionValues).
- `pipeline-svg.tsx`, `PipelineCards.tsx` + their tests DELETED (layered 3D
  abandoned).
- `styles.css`: `pipe-pulse/node-glow/card-float` keyframes replaced by
  `belt-scroll/scan-sweep/item-state`; reduced-motion kill-switch retained.
- `HeroSection.tsx`: static centered copy over `<ConveyorBelt/>`.

### Stations & items (defaults)

- Stations (left→right as belt flows R→L the item meets them in order):
  `Ingest` → `Ground` → `Qualified`.
- ~6 items on the track, content = repo-proof snippets (e.g.
  `network-policies.yaml`, `Kafka migration`, `spot-fleet −38%`).

### Out of scope (unchanged)

- `.glb` models, external art, WebGL.

## Original (superseded) parallax design follows for history

## Goal

Rebuild `HeroSection` around a mouse-tracked 2.5D parallax "data pipeline"
scene built purely from SVG + CSS (no image assets, no WebGL). A single 3D
camera tilt driven by spring-smoothed pointer position gives multi-layer depth
parallax. Headline, eyebrow, and CTAs overlay the scene.

Animation library: **Motion for React only** (no GSAP). Motion+ delivered via
Claude skills (`motion`, `css-spring`, `motion-audit`, `see-transition`).

## Scope

- Whole `HeroSection` rebuild.
- Surviving content: `hero.eyebrow`, the 3-line animated headline, both
  `MagneticButton` CTAs (→ `/sign-in`), `hero.founderNote`.
- Dropped: right-column `resume.pdf` card, floating `RepoCard`s, standalone
  `<Pipeline/>` block, "interviewed at" logos strip.

## Architecture

```
HeroSection (relative overflow-hidden bg-zinc-950)  perspective:1200px
└─ MeshBg (ambient, behind stage, unchanged)
└─ Stage  motion.div  transformStyle:preserve-3d  willChange:transform
          rotateY = useSpring(useTransform(mxNorm → ±8°))
          rotateX = useSpring(useTransform(myNorm → ∓6°))
          spring { stiffness: 80, damping: 20 }
   ├─ BgLayer    translateZ(-150px) scale~1.18  → SVG grid + ambient vector glow
   ├─ CoreLayer  translateZ(0)                  → SVG isometric nodes + cables
   ├─ CardLayer  translateZ(150px)              → floating status cards
   └─ CopyLayer  translateZ(220px) pointer-events-auto
                 → eyebrow + 3-line headline + 2 CTAs + founderNote
```

- Pointer listener on Stage; normalize cursor to −0.5..0.5 of bounding rect.
- Non-copy layers `pointer-events-none`; CopyLayer `pointer-events-auto` so
  CTAs stay clickable through the 3D transform.
- `prefers-reduced-motion`: freeze tilt at 0°, disable pulse + float; headline
  entry fade still plays once.

### New files (`src/features/home/lib/`)

- `PipelineStage.tsx` — pointer/spring engine + layer composition.
- `pipeline-svg.tsx` — BgLayer + CoreLayer SVG markup.

`HeroSection.tsx` becomes a thin layout shell composing `MeshBg` +
`PipelineStage` + copy.

## Data-flow animation

- **Cables:** curved SVG `<path>`, `stroke-dasharray` + animated
  `stroke-dashoffset` via CSS `@keyframes` (off main thread). Teal
  `filter: drop-shadow` glow on the dashed pulse stroke only.
- **Nodes:** isometric rects/diamonds. Sequential light-up via
  `staggerChildren` on CoreLayer mount + phase-offset looping glow keyframe.
- **Floating cards:** 3 cards ("Lead Qualified", "Call Initiated",
  "Resume Grounded"). Independent CSS `translateY` keyframe loops, distinct
  durations (5s/6s/7s) + delays so they never sync — alive when cursor still.
- **Springs:** tilt spring tuned via `css-spring` skill; float = pure CSS
  ease-in-out (no per-frame JS).
- **willChange:** `transform` on Stage + CardLayer; `filter` on glowing pulse
  only. No other properties.

## Edges & testing

- Reduced-motion: static 0° tilt, no pulse, no float; one-shot headline fade.
- SSR: `"use client"` retained; pointer math guarded by `ref.current`.
- Perf gate: `motion-audit` on final component — must rank compositor-only
  (no layout/paint thrash) before completion.
- Tests (Vitest, following existing home test patterns):
  - `PipelineStage` renders all 4 layers.
  - Both CTAs navigate to `/sign-in` on click.
  - Reduced-motion path renders without animation props.

## Out of scope

- `/private/tmp/hero-build/*.glb` 3D models (WebGL path rejected).
- Externally supplied PNG/SVG art (pure-code layers chosen).
- Changes to `MeshBg`, `MagneticButton`, `Pipeline`, `RepoCard` internals.
